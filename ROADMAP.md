# Swift WiFi Roadmap

## Completed (v1.0.0)

- [x] M-Pesa Daraja STK Push integration
- [x] JWT-secured user authentication
- [x] Time-based Wi-Fi packages with speed tiers
- [x] Idempotent M-Pesa callbacks (5-minute replay deduplication)
- [x] Pricing splash page with login/registration
- [x] Transaction history
- [x] In-memory storage backend
- [x] Cloudflare Pages + Functions deployment config
